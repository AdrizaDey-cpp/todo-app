🔹 Project: Todo Web Application

* Built a full-stack web application using Flask and SQLite to manage daily tasks
* Implemented secure user authentication (login/signup) using password hashing with Werkzeug
* Designed user-specific data handling so each user can view and manage their own todos
* Developed CRUD functionality (Create, Read, Update, Delete) for task management
* Integrated search functionality to filter tasks dynamically
* Built responsive UI using Bootstrap and custom CSS
* Deployed and version-controlled using GitHub
